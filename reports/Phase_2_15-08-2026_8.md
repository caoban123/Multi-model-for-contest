# Phase 2 Report 8 - Metadata Search Mode In UI

Date: 15-08-2026

Starting commit: `01ea28d Add UI pins and search history`

## Scope

Triển khai metadata search như một chế độ riêng trong local retrieval UI. Mục tiêu là cho phép team tìm theo thông tin video như title, author, ngày đăng, description và keywords mà không trộn nhầm với visual CLIP search hiện tại.

## Changes

- Thêm API `GET /api/metadata-search` trong retrieval UI server.
- Thêm tham số CLI `--metadata-dir`, mặc định là `data\media-info`.
- Nạp metadata documents theo `--groups`; health API trả thêm `metadata_documents`.
- Thêm tab `Visual` và `Metadata` trong giao diện.
- `Visual` vẫn dùng CLIP text/image feature theo keyframe.
- `Metadata` dùng lexical metadata search ở cấp video, trả kết quả không có thumbnail/keyframe.
- Pins, search history và CSV export hiểu thêm cột `mode`.
- Metadata mode không dùng `clip_query`, không dùng candidate pool và không gọi translation.
