## What Changed

- Removed raw digit presence as a BM25 trigger.
- Removed standalone `số` as an exact marker because phrases such as `một trong số đó` are not OCR intent.
- Kept explicit OCR triggers including quoted text, signs, tables, addresses, countdowns, codes and exact-number questions.
- Split long visual narratives on sentence boundaries and temporal connectors.
- Raised bounded CLIP prompt capacity from four to six.
- Prevented generic `person` from becoming an automatic object-store constraint.
- Required explicit visual color context; `bí đỏ` is now treated as pumpkin rather than a red attribute.
- Updated the Gemini planner prompt so visible counts remain visual and Vietnamese compounds are interpreted semantically.
- Bumped local planner to `phase6-rule-planner-v3` and hybrid plan to `hybrid-query-plan-v6`.
- Added bounded per-subquery candidate rescue: retain the first three RRF consensus videos, then round-robin up to two leaders from each visual lane into the review window.
- Added `All` and `Q1`-`Q6` lane filters to `/submission`; filtering hides cards in place and preserves entered selections/frame IDs.
