## What Changed
- Added one-batch CLIP text encoding for all event visual queries and controlled variants.
- Added one matrix multiplication batch NumPy search with deterministic ranking equivalent to individual search.
- Fused query variants and modalities with configurable RRF while preserving raw source score, raw source rank, query variant and provenance.
- Added Adaptive Top-K bounded by typed min/default/max and driven by genericity, planner confidence, structured constraints and observed top-score margin.
- Added inspectable distinctiveness components: score margin, video concentration, constraint specificity and lexical specificity.
- Selected exactly one required anchor by maximum configurable distinctiveness/evidence tie-break; event position is not hard-coded.
- Anchor evidence now participates in candidate-video ordering after required coverage.
