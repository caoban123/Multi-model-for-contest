# Phase 2 Report 9 - Keyframe Neighborhood Viewer

Date: 15-08-2026

Starting commit: `f59e55b Add metadata search mode to UI`

## Scope

Triển khai keyframe-neighborhood viewer trong local retrieval UI để xem nhanh các keyframe trước/sau một visual result. Tính năng này giúp kiểm tra ngữ cảnh quanh frame được retrieve trước khi pin hoặc chấm judgement.

## Changes

- Thêm API `GET /api/neighborhood`.
- API nhận `video_id`, `keyframe_id`, `radius` và trả danh sách frame lân cận trong cùng video.
- Backend dùng `refs.json` từ NumPy index, không đọc lại mapping CSV mỗi lần click.
- UI thêm nút `Neighbors` trong visual result card.
- Khi bấm `Neighbors`, UI mở một strip thumbnail ngang, đánh dấu keyframe trung tâm.
- Metadata result không hiện nút `Neighbors` vì metadata search là kết quả cấp video, không có keyframe trung tâm.
- README cập nhật trạng thái Phase 2 và cách dùng viewer.
