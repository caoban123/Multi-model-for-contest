# Phase 4 Report 16 - Pin Review Workflow And Richer Exports

## Scope

- Improved the browser-local pin workflow for result review.
- Made pinned candidates easier to reopen against raw videos.
- Added richer review and pinned CSV fields for team handoff.

## Implementation

- Pins now store:
  - query text
  - CLIP query
  - mode and ranking mode
  - rank at pin time
  - manual judgement
  - manual notes
  - full normalized result snapshot
- If a reviewer pins first and then changes `Good` / `Partial` / `Bad` or notes, the saved pin is updated automatically.
- The Pins panel now shows:
  - video/keyframe
  - timestamp
  - rank
  - judgement
  - query text
  - `Open video` when raw video is available
  - `Unpin`
- `Open video` is shared by result cards and pinned candidates, so the same timestamp seeking behavior is reused.

## Export Changes

`Export CSV` now includes:

- `is_pinned`
- `pinned_at`
- `video_url`
- `watch_url`
- `description_preview`

`Export Pins` now includes:

- `manual_judgement`
- `manual_notes`
- `submission_video_id`
- `submission_keyframe_id`
- `submission_pts_time`
- `video_url`
- `watch_url`
- `description_preview`
