## Milestone Result

Official CSV output now follows the organizer examples visually, and each CSV in `/submission` is directly editable without a separate Edit or Apply step.

## Output Contract

Generated rows now use these forms:

```text
KIS:   L00_V000, 1234
Q&A:   L01_V028, 3450, "5"
TRAKE: L10_V001, 1200, 1850, 2100, 2450
```

Rules retained:

- one CSV file per Query ID;
- no header;
- UTF-8 output;
- at most 100 predictions;
- Q&A answer length at most 100 characters;
- TRAKE frame count equals event count;
- TRAKE event frame order is preserved.

Q&A answers are always enclosed in double quotes. Double quotes inside an answer are escaped by doubling them. The parser now accepts spaces after delimiters, so generated output and manually edited rows round-trip correctly.

## UI Change

CSV textareas are editable immediately for ACTIVE sessions. Each file has three independent controls:

- `Reset` restores the current persisted queue version;
- `Save changes` stores the edited rows in the SQLite queue;
- `Download` saves that query CSV independently.

There is no longer a separate `Edit` or `Apply` button. Validate and Done remain unavailable while a textarea contains unsaved changes.
