## What Changed

- Added immutable `StructuredQuery` and `ObjectConstraint` models with validated modes/configuration.
- Added configurable deep CLIP frame pool, object frame candidates and structured metadata video candidates.
- Added deterministic union keyed by `(video_id, keyframe_id)` with modality-specific ranks/scores and evidence.
- Implemented hard intersection, soft support and disabled exclusion for CLIP/object/metadata channels.
- Added representative selection for metadata video candidates: existing best CLIP candidate, then object candidate, then actual best CLIP frame inside that video.
- Preserved a metadata-only video candidate with no frame when no real frame evidence can be computed; no synthetic score is created.

## Benchmark / Metrics

- Candidate counts above are diagnostic coverage, not relevance metrics.
- Raw modality scores remain separate:
  - `clip_score`: cosine similarity from the current index;
  - `object_score`: detection-derived score;
  - `metadata_score`: always null for structured hard filters.
- No direct score addition occurs and no fusion score exists in P4.5.

## Open Issues

- **OPEN:** Multiple object constraints currently execute as separate indexed store queries; correctness is preserved, but a combined SQL plan could reduce latency.
- **OPEN:** Metadata-only retrieval without visual/object evidence can only return a video-level candidate, not a representative frame.
