## Configuration

Set the translation API through environment variables before starting the UI:

```powershell
$env:AIC_TRANSLATION_API_KEY="<your-api-key>"
$env:AIC_TRANSLATION_API_URL="https://api.openai.com/v1/chat/completions"
$env:AIC_TRANSLATION_MODEL="gpt-4o-mini"
```

For another OpenAI-compatible provider, change `AIC_TRANSLATION_API_URL` and `AIC_TRANSLATION_MODEL`. Do not commit secrets to the repository.

## Security Notes
