## Scalability Fix Before Corpus Build

The previous object-to-text corpus path accumulated labels for every frame in a global dictionary. This was acceptable for L21 but risky at 177,321 frames. It now streams ordered rows and emits each object document when the frame key changes.

- Output schema, deterministic ordering, IDs and checksum rules are unchanged.
- Multi-frame regression coverage was added.
- Real L23 smoke: 2,323 object documents in 10.87 seconds.
- L23 smoke peak Python allocation measured by `tracemalloc`: 5.61 MiB.
- Three of 2,326 L23 frames had no object label at confidence >= 0.3 and therefore correctly produced no object text document.
