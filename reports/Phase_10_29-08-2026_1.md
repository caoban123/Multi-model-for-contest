## What Changed

- Added shared bounded Stage-B frame localization for Q&A. It rescans only frames from Stage-A videos, preserves video ranking and returns a temporally diverse shortlist.
- Added optional allowlisted Gemini frame reranking. Gemini can score only the supplied candidate IDs and can reorder frames only inside a video.
- Added optional Gemini multi-image TRAKE verification behind the existing confidence, network and decision-log gates. It is advisory only and never modifies server-selected video/frame/order.
- Added Q&A frame-search controls, per-video contact strips, visual scores, preview actions and frame-field helper to `/submission`.
- Added TRAKE verifier controls and readable advisory traces to `/submission`.
- Added inheritable TRAKE configs and `configs/phase10_trake_gemini_opt_in.json`; the baseline remains VLM-disabled.
- Added object-store confidence filtering, per-label NMS and frame Top-N controls. Omitting flags preserves the baseline bit-for-bit behavior contract.
- Added `tools/phase10_upgrade_audit.py` for Phase 5/corpus/BGE/BM25/object provenance and readiness checks.

- Gemini can return malformed JSON, fail, or add latency. Allowlist parsing and fallback preserve baseline output.
- Deep frame search improves candidate inspection but may not improve official frame accuracy without labelled evaluation.
- BGE v2 and object v2 can regress ranking despite looking richer; neither is a default until ablation passes.
- ASR absence means speech-heavy queries remain under-supported outside two videos.
