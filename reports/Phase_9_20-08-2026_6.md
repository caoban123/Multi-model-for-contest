## Upgrade Opportunities

- Route visual descriptions to CLIP only by default.
- Route exact names, dates, quoted text, OCR and ASR terms to BM25.
- Route semantic transcript/content queries to BGE, optionally with BM25.
- Use multi-channel RRF only when the query analysis identifies matching evidence modalities.
- Add an independently pooled text-heavy benchmark before any default promotion.

## Decisions Recorded

- Keep all new retrieval modes opt-in.
- Do not tune RRF weights on the current partial benchmark.
- Do not use full three-channel RRF as the default.
- Preserve CLIP baseline and build H7 around explicit, visible routing decisions and fallbacks.

## Risks

- The reviewed pool favors CLIP because candidates originated from CLIP runs.
- Positive-only video evaluation cannot fully measure false positives or calibrated ranking.
- BGE CPU latency and cold start remain high for interactive use.
- Source coverage gaps can make a correct text route return misleadingly sparse candidates.
