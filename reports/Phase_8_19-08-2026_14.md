# Phase 8 TRAKE V2 — P8.V2.6 Dense Expansion + P8.V2.7 DANTE-inspired Alignment

## Checkpoint scope

These two checkpoints are reported together because the automatic dense path is intentionally ordered as one inseparable pipeline:

`candidate window -> coarse samples -> coarse DANTE alignment -> event-local fine samples -> fine DANTE alignment`.

The existing manual refinement endpoint and the legacy beam aligner remain available. The V2 JSON config selects `dante`; legacy config still constructs the original `TemporalAligner`.

## Implemented

- Added bounded `DenseWindowExpander`; it only decodes the configured Top-M candidate windows.
- Coarse pass samples the full bounded window at configured coarse FPS.
- Fine pass runs only after a coarse chain exists and samples each predicted event neighborhood independently.
- Enforced per-window frame caps and `max_dense_windows`.
- Added cache keys containing window identity, sampling parameters, video stat/path fingerprint, model fingerprint, config fingerprint, and index fingerprint.
- Persisted requested PTS, decoded PTS, seek error estimate, verified FPS, and frame index when the decoder exposes one.
- An absent decoder frame index is explicitly marked as estimated downstream; it is not presented as a guaranteed source frame mapping.
- Added `DanteInspiredAligner` with backpointer paths, strict order/same-frame controls, hard min/max gaps, optional skip transitions, configured transition/skip costs, deterministic tie-breaking, and bounded `O(events * candidates * beam)` state expansion.
- Dense selections retain the source keyframe identity and provenance while storing the decoded timestamp separately.
- Added dense coarse/fine state persistence, diagnostics, and `dense_decode` stage timing.
- Export distinguishes `dense_video_seek` from `validated_index_ref` mappings.

This is a **DANTE-inspired temporal DP**, not a claim of an exact paper reproduction.

## Verification

- Dense/config/refinement subset: `8 passed`.
- DANTE/dense/alignment/workflow subset: `24 passed`.
- Required DANTE cases cover monotonic selection, reverse rejection, min/max hard gaps, optional skip, same-frame toggle, multiple paths, DP-vs-greedy, deterministic ties, dense sequence, missing required event, and long-list sanity.
- Synthetic long-list sanity: 3,000 candidates, beam 20, Top-3 chains: `233.016 ms` on this workstation.
- `git diff --check`: no whitespace errors; only existing LF-to-CRLF conversion warnings.

## Evidence boundary

The tests establish algorithmic correctness, bounds, persistence, and deterministic behavior. No labelled timestamp development set is present, so timestamp-precision improvement is deliberately recorded as `null`/unmeasured. The synthetic timing is not a production L21 latency claim.

## Concurrent OCR safety

The existing EasyOCR writer was not stopped, restarted, or modified. Its output grew to 6,052 JSONL rows during this checkpoint, confirming that the TRAKE work did not take ownership of that pipeline.
