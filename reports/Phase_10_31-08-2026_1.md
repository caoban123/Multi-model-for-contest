## Changes

### Vietnamese Query Routing

- Added OCR/exact markers for signs, captions, tables, characters, numbers, addresses and road-name questions.
- Added semantic speech markers for conversations, dialogue, mentioned content and answers.
- Added visual-scene markers so long mixed queries retain CLIP instead of becoming text-only searches.
- Removed the overly broad Vietnamese preposition `về` from semantic routing.
- Removed generic `video`/`clip` visual markers so metadata/date queries do not unnecessarily invoke CLIP.
- Removed generic trailing `Hỏi` from speech routing because it describes the competition question, not necessarily speech inside the video.
- RRF remains enabled only when deterministic routing selects more than one retriever.

### Long Query Decomposition

- The local planner now separates an explicit trailing `Hỏi`, `Hãy cho biết`, `Cho biết` or `Question` clause from the visual scene description.
- CLIP receives the scene description instead of answer wording such as `số mấy` or `đường nào`.
- BGE/BM25 still receive the original semantic and lexical query so answer clues are not discarded.
- The public query-plan and Agent response schemas remain backward compatible.

### Competition Profile

- Changed `bge_index_dir` from `l21_l30_bge` to `l21_l30_bge_v2`.
- Raised the BGE minimum from 173,393 to 292,488 documents.
- Updated README artifact inventory, expanded command and current runtime status.
- Added a static regression test preventing the shipped competition profile from silently returning to the stale pre-OCR BGE index.

## Routing Examples

### Visual plus OCR

Input:

```text
Cảnh quay chiếc xe màu trắng rẽ trái. Hỏi con số ghi trên hông xe là số mấy?
```

Validated route:

```text
CLIP + BM25 -> RRF
```

The CLIP query excludes the trailing answer question. BM25 keeps the original number/text terms and is restricted to OCR evidence.

### Visual plus Speech plus Address

Input:

```text
Một cụ ông trò chuyện với nhóm người nước ngoài. Hỏi quán trọ nằm trên đường nào?
```

Validated route:

```text
CLIP + BGE + BM25 -> RRF
```

BGE/BM25 use ASR/OCR source filters. The ASR partial-coverage warning remains visible.

### Pure Metadata Date

Input:

```text
video xuất bản ngày 31 tháng 8 năm 2024
```

Validated route:

```text
BM25 only
```

The generic word `video` no longer causes an unnecessary CLIP search.
