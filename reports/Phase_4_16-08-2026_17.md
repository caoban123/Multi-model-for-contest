# Phase 4 Report 17 - Attribute/Color Evidence For Structured Retrieval

## Scope

- Added a general attribute/color evidence channel to opt-in structured retrieval.
- The goal is to improve queries such as `person wearing a red shirt` without hardcoding one special case.
- Default `/api/search` remains unchanged.

## Implementation

- Added `src/aic_retrieval/color_attributes.py`.
  - Parses color constraints from query text or `attribute_color`.
  - Supports common English and Vietnamese color aliases.
  - Scores keyframe images by color ratio using Pillow and NumPy.
  - Uses a lightweight center/upper-body crop when query suggests clothing.
- Extended `StructuredQuery` with:
  - `enable_attributes`
  - `attribute_constraints`
  - `attribute_mode`
- Extended structured candidate generation:
  - Adds `attribute_rank`
  - Adds `attribute_score`
  - Adds frame-level `evidence.attribute`
  - Supports soft support and hard requirement mode.
- Extended RRF fusion:
  - Added `weight_attribute`.
  - Attribute evidence participates in frame fusion, video fusion and representative-frame selection.
- Extended retrieval UI:
  - Added `Attributes` checkbox.
  - Added optional `Color` input.
  - Added attribute soft/hard mode.
  - Added attribute evidence chips and CSV export fields.

## Usage

UI:

1. Open `Structured Filters`.
2. Tick `Use experimental structured retrieval`.
3. Keep `CLIP` enabled.
4. Tick `Attributes`.
5. Search `person wearing a red shirt`.
6. Leave `Color` blank to auto-parse `red`, or type a color manually.

API:

```text
/api/structured-search?q=person+wearing+a+red+shirt&top_k=12&candidate_pool=100&enable_clip=true&enable_attributes=true&attribute_filter_mode=soft&fusion_method=rrf
```

## Notes

- This is a lightweight image-color signal, not a full clothing/person attribute model.
- It can still be confused by red backgrounds, red text or red objects.
- It is kept opt-in under Structured Filters and should be manually judged before any default promotion.
