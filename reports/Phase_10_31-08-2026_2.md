## Changes

### Bounded Visual Decomposition

- Long scene narratives can produce one primary CLIP query plus up to three event-level variants.
- Trailing answer clauses such as `Hoi`, `Hay cho biet`, `Cho biet` and `Question` are excluded from visual prompts.
- Temporal markers include `sau do`, `tiep theo`, `cuoi cung`, `then`, `after that` and `finally`.
- Gemini planner output may provide a `clip_queries` array, but deterministic validation limits it to four non-empty entries.
- The local planner remains the fallback when Gemini is disabled, unavailable or invalid.

### Multi-query CLIP and Fusion

- All CLIP text variants are batch-encoded in one model forward pass when the encoder supports batching.
- Each variant retrieves independently from the existing CLIP NumPy index.
- An inner video-level RRF combines the visual variants and deduplicates video candidates.
- Existing outer RRF then combines the CLIP channel with BGE and BM25 only when the validated route needs multiple retrievers.
- Provenance preserves the visual query text, query rank and contributing frame evidence.
- Submission and main Agent inspectors display the executed `Q1` to `Q4` list.

### OCR Noise Control

- BGE/BM25 fetch a bounded larger text pool before candidate postprocessing.
- Exact normalized OCR duplicates from the same video are collapsed.
- Broad global retrieval keeps at most four OCR hits per video.
- Candidate-local frame refinement does not apply the global four-hit cap, so distinct OCR evidence around the selected video remains inspectable.
- Metadata and ASR hits are not affected by the OCR cap.
- The response exposes input, retained, duplicate-removed and cap-removed counts under `channel_postprocessing`.

### External SSD Resilience

- Registry, metadata and artifact reads already retried transient Windows device errors.
- SHA-256 provenance and audit reads now use the same bounded retry policy.
- Retries cover `errno` 5/22/32 and Windows errors 21/433 with capped exponential delay.
- Persistent and non-transient errors still fail visibly; the change does not hide corrupt or missing files.
