# Phase 8 — semantic seed gate for temporal alignment

## Defect

A chain could satisfy timestamp order only by replacing a strong retrieval
candidate with a much weaker frame. In the observed four-event query, the two
best retrieval frames for the first two events shared the same timestamp. The
path builder then selected an earlier low-ranked news-presenter frame for the
first event, producing a temporally valid but semantically false answer.

## Correction

- Added `temporal.min_alignment_seed_relative_score` (configured as `0.85`).
- Before temporal feasibility/window construction, candidates below 85% of the
  best event retrieval score are removed from alignment eligibility.
- The gate is fail-closed: if no remaining path is both semantically strong and
  strictly ordered, no TRAKE answer is emitted.
- The UI now says that semantic-seed quality and temporal order could not both
  be satisfied, instead of suggesting that alignment succeeded.

## Live verification

The prior four-event query is now rejected after retrieval: no video/frame path
meets both requirements, so the incorrect presenter frame cannot be output.

## Tests

- New regression test: a weak early candidate cannot be substituted merely to
  force temporal order.
- Focused tests passed; preceding full suite: 94 TRAKE tests and 282 repository
  tests passed.
