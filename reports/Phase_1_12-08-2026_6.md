## What Changed

- Added `src/aic_retrieval/metadata_search.py`:
  - Loads video-level `media-info` JSON files.
  - Builds weighted tokens from video id, title, author, publish date, keywords, and description.
  - Uses a lightweight BM25-style lexical score.
  - Normalizes Vietnamese accents for query matching.
  - Supports `min_match` filtering.
- Added `tools/metadata_search.py`:
  - CLI for metadata-only search.
  - Writes JSON and optional CSV output.
- Added `tests/test_metadata_search.py`.
- Updated README with metadata search usage.

## Sample Results

Query: `60 giay sang 01082024`, groups `L21`.

- Top-1: `L21_V001`.
- Matched terms: `60`, `giay`, `sang`, `01082024`.
- Interpretation: good result for exact title/date lookup.

Query: `Bao Tuoi Tre`, all metadata.

- Top-5 are `Bao Tuoi Tre` author results from L30.
- Interpretation: good result for author/channel lookup.

Query: `HTV Sports bong da`, all metadata.

- Top-2 are `HTV Sports` results.
- Lower results include ViVU food videos because accent-insensitive matching treats `bong`/`bông` and `bóng` similarly.
- Interpretation: metadata search is useful, but token normalization can create false positives for short Vietnamese terms.

## Upgrade Opportunities

- Add exact phrase bonus for title, author, and keywords.
- Keep both accent-sensitive and accent-insensitive tokens so exact Vietnamese matches can outrank stripped matches.
- Add a metadata benchmark file with expected video ids for date/channel/title queries.
- Build a two-column review artifact showing metadata-only results beside CLIP visual results.

## Decisions Needed

- Whether metadata should remain a separate search mode or become a candidate generator.
- Whether to add phrase/exact-match scoring before any CLIP fusion experiment.

## Risks

- Metadata search can find the right video-level item but not the exact keyframe.
- Accent-insensitive matching improves usability but can introduce false positives.
- Non-L21 metadata can be searched, but non-L21 visual display remains limited without keyframe images.
