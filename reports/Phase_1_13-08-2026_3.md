## Index Artifact Note

After the merge, an old local index may fail with:

```text
index provenance is incomplete
```

That is expected if the artifact was built before provenance validation was added. Rebuild local indexes with:

```powershell
python tools\build_numpy_index.py --registry artifacts\registry\data_registry.json --groups L21 --output-dir artifacts\indexes\l21_numpy
```

Do not commit `artifacts/`; every contributor should rebuild indexes from local data.
