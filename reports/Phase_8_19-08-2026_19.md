## Outputs and isolation

The runner supports machine-readable JSON and human-readable Markdown. Every row contains:

- exact config fingerprint and algorithm version;
- Event Recall@K, Video Recall@K, chain success, temporal order, timestamp tolerance, and latency fields;
- explicit status (`EVALUATED`, `UNAVAILABLE_LABELS`, `NOT_RUN`, or guarded skip).

Evaluation is fingerprint-isolated. A variant with no matching persisted session is `NOT_RUN`; it is not evaluated using another variant’s session. Missing labels/sessions produce null metrics, never fabricated zeroes.
