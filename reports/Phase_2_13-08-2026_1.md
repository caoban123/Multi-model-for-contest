## Current Status

Phase 2 has started with a usable local retrieval UI for L21.

Implemented:

- Local HTTP server using the Python standard library.
- Browser UI with query input, Top-K, candidate-pool controls, loading/error/empty states, and result grid.
- Text query search through CLIP text encoder and the existing persistent NumPy index.
- L21 keyframe thumbnails served from local `data/keyframes`.
- Per-result display of `video_id`, `keyframe_id`, timestamp, score, title, author, publish date, and keywords.
- Missing-image state for results without a local keyframe image.
- Safe keyframe path resolution to avoid serving files outside the repository.

Not implemented yet:

- Pin result.
- Search history.
- Judgement buttons and CSV export.
- Paging/lazy loading beyond the current Top-K grid.
- Neighborhood viewer around a keyframe.
- Metadata/visual comparison tabs.

## How To Run

Rebuild the L21 index if needed:

```powershell
python tools\build_numpy_index.py --registry artifacts\registry\data_registry.json --groups L21 --output-dir artifacts\indexes\l21_numpy
```

Start the UI:

```powershell
python tools\retrieval_ui.py --registry artifacts\registry\data_registry.json --index-dir artifacts\indexes\l21_numpy --groups L21 --clip-local-files-only
```

Open:

```text
http://127.0.0.1:8765/
```

If `--clip-local-files-only` is used, the CLIP model must already exist in local HuggingFace cache or the path provided through `AIC_CLIP_MODEL_ID` / `AIC_CLIP_CACHE_DIR`.

## Design Notes

- The UI is a work surface, not a landing page.
- The first screen is the search experience.
- Cards are used only for individual repeated results.
- Images are loaded per displayed result, not all at once.
- The server validates the persistent index using Phase-1 provenance before serving search.

## Data Status

This UI is currently intended for the verified L21 local baseline:

- L21 index: 7,800 vectors, 512 dimensions.
- L21 keyframe images: available on this machine.
- Non-L21 visual display remains limited by missing keyframe images.
