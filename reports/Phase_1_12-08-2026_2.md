## Upgrade Opportunities

- Change benchmark generation to store full candidate pool, then judge Top-10/Top-20 for weak queries.
- Add interaction-aware heuristics using boxes, such as hand-phone proximity, before trying object boost again.
- Add query-type tags to benchmark queries.
- Clean metadata mojibake before metadata fusion.

## Decisions Needed

- Whether to expand manual judgement beyond Top-5 for weak queries.
- Whether to invest in box-geometry heuristics for interaction queries like `hand holding a phone`.
- Whether to defer fusion and move to metadata cleanup first.

## Risks

- Object-only fusion can reinforce wrong frames when detector finds the queried object but the relation/action is wrong.
- Current fusion experiment cannot evaluate candidates outside the judged Top-5.
- Object detector does not directly solve color attributes such as `red shirt`.
- Metadata has mojibake and should not be trusted for text fusion until cleaned.
