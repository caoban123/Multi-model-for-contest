## Current Status

The UI translation feature now supports Gemini API keys natively. Gemini is the default translation provider. OpenAI-compatible translation remains available for future providers.

## What Changed

- Added Gemini Generate Content support in `src/aic_retrieval/translation.py`.
- Gemini default endpoint base: `https://generativelanguage.googleapis.com/v1beta`.
- Gemini default model: `gemini-2.0-flash`.
- Gemini API key is sent through the `x-goog-api-key` header.
- Added `AIC_TRANSLATION_PROVIDER` support in `tools/retrieval_ui.py`.
- `/api/health` now reports translation provider and model.
- README now documents Gemini-specific environment variables.

## Configuration

Recommended Gemini setup:

```powershell
$env:AIC_TRANSLATION_API_KEY="<your-gemini-api-key>"
$env:AIC_TRANSLATION_PROVIDER="gemini"
$env:AIC_TRANSLATION_MODEL="gemini-2.0-flash"
```

Then run the UI normally:

```powershell
python tools\retrieval_ui.py --registry artifacts\registry\data_registry.json --index-dir artifacts\indexes\l21_numpy --groups L21 --clip-local-files-only
```

Do not commit API keys. If a key was pasted into chat or shell history, rotate it if the team considers that exposure risky.
