## Decisions Recorded

- Mark H7 `VERIFIED_OPT_IN` rather than promoting it to default.
- Keep CLIP baseline one click away in every existing UI.
- Use Hybrid video-level RRF for KIS/Q&A candidates.
- Use frame-level event fusion for TRAKE; do not feed video-level RRF directly into temporal alignment.
- Keep Gemini optional and always retain deterministic local planner fallback.
- Do not treat H7 smoke results as evidence of quality improvement.

## Risks

- BGE cold start is visible on CPU and must be warmed before time-critical use.
- Gemini availability, latency and response format depend on an external API.
- Sparse OCR/ASR coverage can route a valid text query to weak evidence.
- TRAKE BGE/BM25 evidence can improve recall but still requires temporal and semantic human review.
- Static UI tests cannot detect all visual overlap or browser-specific behavior.
