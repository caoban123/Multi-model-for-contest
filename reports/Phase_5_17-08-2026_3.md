## Root Cause

1. `build_phase5_store.py` gọi thẳng `load_numpy_index()` và giả định persistent index đã tồn tại.
2. Không có orchestration nối `data_registry.py` -> `build_numpy_index.py` -> `build_phase5_store.py`.
3. `load_numpy_index()` gộp mọi trường hợp thiếu file thành thông báo `missing NumPy index files in ...`, không chỉ rõ `vectors.npy` hay `refs.json`.
4. OCR/ASR JSONL từng được đặt dưới `artifacts/`; xóa `artifacts/` làm mất cả evidence input. Repo chỉ có bounded raw pilot, chưa có production full-corpus normalizer/extractor tạo hai JSONL schema-compatible.
5. `phase5_search.py` không hướng dẫn cách rebuild store khi file SQLite thiếu.

## Actual Pipeline

```text
data/clip-features-32/*.npy + data/map-keyframes/*.csv
  -> tools/data_registry.py
  -> artifacts/registry/data_registry.json
  -> tools/build_numpy_index.py
  -> artifacts/indexes/l21_numpy/vectors.npy
  -> artifacts/indexes/l21_numpy/refs.json
  -> artifacts/indexes/l21_numpy/metadata.json
  -> reviewed schema-compatible OCR/ASR JSONL
  -> tools/build_phase5_store.py
  -> Phase 5 SQLite store
  -> tools/phase5_search.py
```

`data/keyframes` cần cho OCR inference/visual evidence; `data/videos` cần cho ASR inference. Hai thư mục này không thay thế CLIP feature và mapping là prerequisite trực tiếp của NumPy index.
