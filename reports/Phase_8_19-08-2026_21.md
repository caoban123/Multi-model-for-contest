# Phase 8 — TRAKE V2 semantic-evidence correction

## Implemented

- Dense refinement now samples locally around each per-event source candidate,
  applies a bounded refinement shift, and persists the actual decoded dense
  image used for a final event. The final timeline no longer reuses a stale
  retrieval thumbnail as if it were refined evidence.
- A multi-event request receives a default hard 60-second transition limit;
  explicit temporal language can tighten or relax that default.
- Dense chains are hard-rejected when adjacent visual scene signatures do not
  meet the configured continuity threshold.
- A chain assembled only from CLIP and scene continuity is explicitly marked
  `REQUIRES_MANUAL_REVIEW`. It is not an automatic proof that the requested
  actions occurred.
- The UI labels the result as a dense temporal/scene-consistent candidate and
  explains this limitation before the existing Confirm action.

## Boundary

CLIP can rank frames and compare scene continuity, but cannot reliably prove
fine-grained temporal actions such as walking in, opening a door, and sitting
down. Automatic action verification needs an action/video-language verifier or
ground-truth annotation; the configured VLM path remains disabled.
