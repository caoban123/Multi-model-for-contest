## Upgrade Opportunities

- Metadata cleanup may be more useful than object boost for location/news context queries.
- A learned or CLIP-based reranker may be safer than hand-written object boosts.
- Add color-sensitive reranking for q010 only after an explicit color extraction strategy exists.
- Add query-type tags and per-type metrics.

## Decisions Needed

- Whether to stop object-only fusion for now and move to metadata cleanup.
- Whether to create a small reranker dataset from judged CSVs.
- Whether to add OCR/color features later for attribute queries.

## Risks

- Object-only fusion can actively worsen ranking.
- Phone-hand box proximity is too weak/noisy with current object detections.
- Metadata remains mojibake and should be cleaned before metadata fusion.
