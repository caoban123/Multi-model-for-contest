# Phase 8 TRAKE V2 — P8.V2.11 Final Reranking + P8.V2.12 VLM Status

## P8.V2.11 — explicit final reranking

- Added late chain reranking with configured weights for:
  - `event_semantic_score`
  - `temporal_score`
  - `context_score`
  - `linkage_score`
  - `coverage_score`
  - `multimodal_evidence_score`
- All starting weights and multimodal/linkage parameters are in the typed V2 JSON config and fingerprint.
- Missing `UNKNOWN` context/linkage evidence is omitted and the remaining weights are renormalized.
- A missing required event is dropped before scoring and cannot be rescued by coverage or any soft score.
- Every chain persists the values, weights actually used, method versions, and per-event/per-link breakdown so the UI/API can explain why chain #1 outranks chain #2.
- Reranking is a distinct timed stage and diagnostics retain the before/after chain IDs.

## P8.V2.12 — optional VLM remains off

Current default remains:

```text
enabled=false
network_calls_allowed=false
decision_log_approved=false
provider=null
model=null
```

No provider call, model download, or network use was performed.

The dormant injected-verifier boundary is hardened for future approved use:

- enabling requires network permission, decision-log approval, provider, and model;
- only low-confidence triggers are eligible (small Top-1/Top-2 margin, low linkage, low event confidence, or OOD marker);
- only configured Top-N chain evidence is copied to a narrow payload;
- cross-video, missing-required, invalid, or non-monotonic chains are rejected before a verifier call;
- the result is advisory-only and cannot alter server selection/invariants.
